# cF 与 tI 的关系，及 14 种布拉维点阵的对称性等效与退化

> 用户原话：“对比 cF 与 tI 的关系，探究 14 种布拉维点阵的对称性等效与退化。”
>
> 本报告所有数字都由 `scripts/bain_path.py` 与 `scripts/bravais14.py` 用 **spglib** 实算得到，
> 并逐项记录在同目录的 CSV 中；正文引用处标注了对应的 CSV 文件。

---

## 0. 结论速览

1. **cF（面心立方，Fm-3m #225）与 tI（体心四方，I4/mmm #139）不是同一个点阵/空间群**：
   点群分别是 **m-3m（阶 48）** 与 **4/mmm（阶 16）**。它们只在 bct 胞的
   **特殊度量 `c/a = √2`** 处等价——此时 bct 胞恰好可以描述 fcc 晶体。
   （`equivalences.csv` E00 对照 / E02；`bain_path.csv` 精确 √2 行）
2. 沿 **Bain 路径**（a_t = a_c/√2 固定、c/a 从 0.90 扫到 1.70，步长 0.01）：
   81 个网格点中 **80 个是 tI（I4/mmm，32 个常规胞对称操作）**，
   只有精确的 **c/a = 1**（→ cI, Im-3m）与 **c/a = √2**（→ cF, Fm-3m）两处对称性跳升。
   （`bain_path.csv`：82 行 = 80 个网格点 + 2 个精确特殊点）
3. **14 种布拉维点阵**全部构造复核成功：14/14 与“全息对称（holohedry）”空间群一致
   （`bravais14.csv`，`verified=1`）。
4. 实测验证 **12 组**特殊度量下的等价/退化关系（`equivalences.csv` E00–E11，12/12 通过）：
   - bct：c/a=1 → cI；c/a=√2 → cF
   - 菱方 hR：α=60° → cF；α=90° → cP；α=109.4712° → cI
   - oC(a=b) → tP；oP(a=b) → tP；oP(a=b=c) → cP；mP(β=90°) → oP；
     mC(β=90°) → oC；tP(c=a) → cP
5. 对称性的“恢复”只发生在**精确的**特殊度量处；spglib 的 `symprec` 会把一个有限窗口
   内的近似度量也判成高对称（`bain_tolerance.csv` 给出 0.01 Å 与 0.05 Å 两种容差的对照）。

## 1. 方法：构造胞 → spglib 判定

对每个构造好的 pymatgen `Structure`：

1. 调用 `spglib.get_symmetry_dataset(cell, symprec=...)` 得到空间群号、国际记号、
   点群、Wyckoff 字母、标准胞（`std_lattice`）与约化胞（`primitive_lattice`）；
2. **点群阶**与**常规胞操作数**由 `spglib.get_symmetry_from_database(hall_number)` 得到
   （这样跨 setting 可比：cP=48、tI=32、cI=96、cF=192）；
3. **Bravais 类型**由空间群号 → 晶系字母（a/m/o/t/h/c）+ 国际记号首字母（P/C/I/F/R）拼出，
   例如 `Fm-3m → cF`、`I4/mmm → tI`、`R-3m → hR`；
4. 体积/原子、最近邻距离由 pymatgen 直接计算，用于检查“等价”时密度与键长是否自洽。

> 说明：`bain_path.csv` 的 Bain 扫描使用 **symprec = 0.01 Å**（严格）；其余表使用
> symprec = 0.05 Å。容差的影响单独列在 `bain_tolerance.csv`。

## 2. Bain 路径：cF — tI — cI

### 2.1 几何推导

取 fcc 常规立方胞边长 $a_c$。Bain 提出的 bct 胞为

$$
a_t=b_t=\frac{a_c}{\sqrt2},\qquad c_t=\left(\frac{c}{a}\right)a_t,
$$

基元为 2 个原子：$(0,0,0)$ 与 $(\tfrac12,\tfrac12,\tfrac12)$。于是

* $c/a=\sqrt2$：$c_t=a_c$，该 bct 胞正是 fcc 晶体（2 原子/胞，体积 $a_c^3/2$，$V_{conv}=2V_{bct}$）；
  spglib 实测：空间群 **#225 Fm-3m**，点群 **m-3m**，常规胞操作数 **192**，
  标准胞 $a=b=c=3.615$ Å（= $a_t\sqrt2$，`bain_path.csv` 中 `c_over_a=1.414214` 行的 `std_a/b/c`；
  独立构造的 E02 用 $a_t=2.5562$ Å 时 std 胞为 3.61501 Å，见 `equivalences.csv`）；
* $c/a=1$：$c_t=a_t$，bct 胞变成 bcc 常规胞，spglib 实测 **#229 Im-3m**，
  标准胞 $a=b=c=2.55619$ Å（= $a_t$），常规胞操作数 **96**；
* 其它 $c/a$：**#139 I4/mmm**（tI），点群 **4/mmm**，27 个常规胞操作数 **32**。

Bain 路径上的两个端点属于立方晶系，中间是四方晶系；这正是“**拉伸/压缩一个轴**”把
立方对称性破坏、只在特殊长度比处恢复的图像。

### 2.2 实测扫描（`bain_path.csv`）

| 项目 | 数值 |
|---|---|
| 固定参数 | $a_t = a_c/\sqrt2 = 2.556191$ Å（$a_c=3.6150$ Å，Cu） |
| 扫描范围 | `c/a = 0.90 → 1.70`，步长 0.01（81 个网格点） |
| 额外精确点 | `c/a = 1`、`c/a = √2`（`is_special=1`），CSV 共 **82 行** |
| tI 区间 | `0.90–1.70` 共 **80 个网格点**全部为 #139 I4/mmm（点群 4/mmm，n_symops_conv=32） |
| c/a = 1（精确） | #229 Im-3m，点群 m-3m，n_symops_conv=96，std a = 2.55619 Å |
| c/a = √2（精确） | #225 Fm-3m，点群 m-3m，n_symops_conv=192，std a = 3.615 Å |
| 每原子体积 | 随 c/a 变化（见 CSV `volume_per_atom` 列），说明 Bain 路径是**非等体积**应变路径 |
| 最近邻距离 | `nn_distance` 列（c/a=1 时 2.21373 Å；c/a=√2 时 2.55619 Å） |

> **容差效应**（`bain_tolerance.csv`）：同一批 bct 胞，symprec=0.01 Å 时
> c/a=0.99/1.01 仍是 tI；symprec=0.05 Å 时被判成 cI。因为 $|c_t-a_t| = 0.0256$ Å
> 小于 0.05 Å。同理 c/a=1.41/1.42 在 0.05 Å 下被判成 cF。
> **结论**：报告“特殊度量处对称性恢复”时，必须同时报告 symprec。

### 2.3 为什么“cF ≡ tI”不等于“点群相同”

| 量 | cF（fcc） | tI（bct，一般 c/a） |
|---|---|---|
| 空间群 | Fm-3m (#225) | I4/mmm (#139) |
| 点群 | **m-3m**（$O_h$，阶 48） | **4/mmm**（$D_{4h}$，阶 16） |
| Bravais 类型 | cF（面心立方） | tI（体心四方） |
| 常规胞操作数 | 192 | 32 |
| 晶系 | 立方 | 四方 |
| 实测证据 | `equivalences.csv` E02 | `equivalences.csv` E00 |

**“等价”指的是**：在 $c/a=\sqrt2$ 这个**特殊度量**下，bct 胞的平移群 + 2 原子基元恰好
与 fcc 晶体相同（同一晶体、不同胞选择）。**离开这个度量**，bct 晶体就是四方晶体，
点群从 m-3m 降到 4/mmm，空间群从 #225 降到 #139。所以：

> cF 与 tI 的等价是**特殊度量下的等价**，不是点群相同；更不是“tI 是 cF 的近似/超集”。
> 反过来，任意 fcc 晶体都**可以**用 bct 胞描述，但任意 tI 晶体**不能**称为 fcc。

**14 种点阵与 7 晶系 / 32 点群 / 全息对称的关系**

* 晶体学点群共 **32** 个；其中每个晶系恰有一个**全息点群**（holohedry，即该晶系点阵的
  最大点群），共 **7** 个：三斜 -1、单斜 2/m、正交 mmm、四方 4/mmm、
  三方 -3m、六方 6/mmm、立方 m-3m（与 `bravais14.csv` 的 `holohedry_point_group` 列一致）。
* **14 种布拉维点阵 = 7 个晶系 × 该晶系允许的心化方式**：
  三斜 1 种（P）、单斜 2 种（P、C）、正交 4 种（P、C、I、F）、四方 2 种（P、I）、
  三方 1 种（R）、六方 1 种（P）、立方 3 种（P、I、F）→ 1+2+4+2+1+1+3 = **14**。
* 因此 14 种布拉维点阵与 **7 个全息点群**（→ 7 晶系）一一对应到“晶系层”，
  同一点群下的不同心化方式共享同一全息点群（如 oP/oC/oI/oF 都对应 mmm）。
* 每个 Bravais 点阵的**全息对称**就是上表最后一列的空间群（#2, #10, #12, #47, #65, #71,
  #69, #123, #139, #191, #166, #221, #229, #225）；14/14 与 spglib 实测一致。

## 5. 讨论

1. **对称性“退化/恢复”的本质是度量约束**：Bravais 点阵的对称性由度规（晶胞参数）决定。
   当连续改变一个参数（c/a 或 α）时，空间群在一般点是低对称的；只有在参数取到
   使晶胞同时满足更高对称性要求的**特殊值**时，才“跳”回高对称。Bain 路径与 hR 的
   α 扫描是同一个数学现象在两个不同参数方向上的体现。
2. **“等价”是胞选择层面的等价**：cF≡tI（c/a=√2）、cF≡hR（α=60°）、cI≡hR（α=109.47°）
   都是“同一个晶体可以用不同 Bravais 型式的胞描述”。把这种描述层面的等价误读成
   “点群相同”是常见的教学误区；本报告用点群阶（48 vs 16）和空间群号（225 vs 139）
   明确区分两者。
3. **容差会制造“假的等价窗口”**：例如 c/a=1.41 时 $|c_t-\sqrt2 a_t|=0.011$ Å，
   在 symprec=0.05 Å 下会被判为 Fm-3m；改用 0.01 Å 就如实判为 I4/mmm。
   因此任何“特殊度量处对称性恢复”的结论都应附 symprec 与度量偏差（`bain_tolerance.csv`）。
4. **14 种点阵 vs 32 点群**：14 是“点阵 + 心化”的数目，32 是点群的数目，两者维度不同；
   14 种点阵各自的全息对称只是 32 个点群中的 **7** 个（每个晶系一个）。
   其余 25 个点群对应更低对称的晶体结构（如 mP 的 2/m 之外的 2、m 等非全息点群）。

## 8. 局限 / 未验证

* **Bain 路径没有能量信息**：这里只做“结构 + 对称性”分析，没有做 DFT/势函数计算，
  因此**不讨论** fcc/bcc 的相对稳定性或 Bain 路径的能垒；`volume_per_atom` 也表明
  该路径不是等体积路径（真实 Bain 转变通常用等体积或指定应变路径）。
* **只用了单元素（Cu）虚设晶格**：目的是让点阵对称性不被化学占位破坏；
  不涉及合金有序化、磁序、电荷有序等降低对称性的因素。
* **hR α 扫描的上限止于 115°**：α 更大时（如 120°）spglib 在当前容差下无法给出判定
  （脚本会记录 `note` 并跳过），未做更极端的度量。
* **hP 没有找到特殊度量退化**：对 hP 尝试 c/a = 1、√(3/2)、1.5、1.633 等值，
  spglib 均返回 #191 P6/mmm（`hP` 在不同 c/a 下的确可以是六方点阵的不同度量，
  但不退化为其它 Bravais 型；这一负结果没有写入 CSV，仅在此说明）。
* **“14 种点阵的全息对称空间群”是标准表结论**：本报告用构造 + spglib 复核了
  14/14（每个点阵的最大空间群），但“这 14 个空间群就是 14 种点阵的全息对称”这一
  对应关系的命名来自国际表，未在此做独立数学证明。
